# Mesis
Mesis is a tool that allows to keep HTML source code as a POJO

At the moment is a terrible mess of a code (working, but you can use it as an example of what NOT to do) and I intend to refactor it from square one.

Mesis is written in C++ using Emscripten as a WebAssembly.

It is a single-file project that can be compiled using Emscripten without mantaining a MAKE file.
